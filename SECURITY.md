# Security

To report a suspected vulnerability, contact the repository maintainer through an available repository contact path and include only the minimum safe reproduction details. Do not add sensitive material to public channels.

The current boundary assumes a trusted local filesystem and cooperative writers. Human review is required before relying on any change.
